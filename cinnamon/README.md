## Copy and edit

Open a named `.txt` file on GitHub, choose **Raw**, and copy the whole `[dohtml]` block into your post. The hosted stylesheet link is already included. The editable name, URL, title/status, GIFs, time and writing all precede decoration and the stylesheet. Posting snippets and CSS contain no comments, hidden tips or instructions.

Replace `[url]`, `[name]` and `[text]`. Both supplied Tumblr GIF URLs and lorem ipsum are inserted in every template. Replace either image URL and adjust its `object-position` to change the crop. Either portrait, or the whole `cnm-gifs` container, can be removed. The poster is inspiration; it is not embedded in posts.

Comms messages use ordinary `<p>` paragraphs. Successive opening `<p>` tags also work without closing tags. All messages belong to the current poster. Set the wrapper's `data-direction="received"` or `data-direction="sent"` for incoming or outgoing bubbles. The time is editable. Phone hardware is decorative; no forum JavaScript is required. Buds encourage replies of 100 words or fewer; their sample replies are below that limit, and longer replies are never clipped.

Inside `[dohtml]`, use `<b>`, `<i>` and `<u>`. `<strong>` and `<em>` also work. The preview editor accepts `[b]`, `[i]` and `[u]` and converts them to HTML in the copied snippet. Bold and underline use member colours 1 → 2 → 3; italics reverse the gradient to 3 → 2 → 1.

## Preview and editor

Download `cinnamon-collection-preview.html` and open it in your browser. Type tabs and named buttons access all fifteen designs, with Previous/Next navigation and an All 15 designs view. Every design keeps its edits during the current page session. Name, URL, title, GIFs, crops, writing and comms time/direction can be edited. **Copy code** and **Download snippet** include the current edits. The source panel displays the complete code.

Preview palettes and Light/Dark/System modes affect the preview only; copied code inherits the actual forum palette. The preview uses sample names and titles, while GitHub `.txt` files retain the requested placeholders. The bud editor counts words without enforcing a limit. Download an edited snippet to keep it after closing the page.

## Integration

All templates load `cinnamon-collection-v1.css` through jsDelivr. Styles are scoped to `.cnm`, with no global resets or IDs. The inherited, comma-separated RGB variables `--mgrgb1`, `--mgrgb2` and `--mgrgb3` drive the design. The templates do not overwrite those variables. Add a forum group class to the outer wrapper to use that group's colours explicitly.

Blue Hour's `html[color-mode="light"]` and `html[color-mode="dark"]` override the system preference; the system is used only when neither mode is set. Italiana, Lora and DM Sans load from Google Fonts, with local fallbacks. Two original cinnamon engravings are SVG masks embedded in the CSS. Hosted CSS, fonts and GIFs need internet access.

## Designs

- **Ceylon Sonata (thread):** A bound folio with a coloured spine, engraved cinnamon quills and portraits cut into a shallow chevron.
- **Quill and Quiet (thread):** An oversized literary title beside two slender, staggered portrait slivers.
- **Canela Vellum (thread):** A vaulted vellum page with a double inset border and a panoramic portrait ribbon.
- **Barkbound (thread):** A tinted title panel, generous manuscript text and a paired photographic signature beneath.
- **Saigon Silk (thread):** A fine gradient binding with staggered silk-corner portraits and gently bracketed writing.
- **Cindertext (comms):** A contemporary handset with a tiny paired contact image and softly tailed message bubbles.
- **Velvet Relay (comms):** A nostalgic flip-phone silhouette with a double portrait screen, hinge and small keypad.
- **Quillwave (comms):** A slider-style phone with a framed message screen and circular navigation dial.
- **Simmer Signal (comms):** A squared messenger with vertically stacked contact thumbnails and crisp bubble details.
- **Afterglow Inbox (comms):** A lock-screen-inspired phone with a large clock and full-width notification cards.
- **Barklet (bud):** A tiny bound note with two square portraits tucked beside the heading.
- **Curlsong (bud):** A rounded miniature with two slender portraits in the left margin.
- **Silkseed (bud):** A fine-lined reply slip with a narrow portrait strip across the top.
- **Cinderbud (bud):** A double-spined miniature with curled portrait corners and a perforated text divider.
- **Quilltip (bud):** An open little letter with a narrow portrait bookmark in the right margin.
