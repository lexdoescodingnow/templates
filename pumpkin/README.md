# Pumpkin · Dexter & Happy

Fifteen JCink templates: five threads, five phone/device comms and five compact buds. Gourd ribs, seed impressions, carriage curves, patchwork seams and curling vines carry the collection. Member colours lead the headers, frames, devices and text accents over neutral reading surfaces.

[Download the preview and editor](https://github.com/lexdoescodingnow/templates/raw/refs/heads/main/pumpkin/pumpkin-collection-preview.html)

Open a named `.txt` file below and choose **Copy raw file** on GitHub. Paste the complete block into your post. The `[dohtml]` tags and hosted stylesheet link are already included.

Download the HTML preview and open it in a browser to browse, edit and copy the designs. The preview includes its CSS and editor; GIFs load from Tumblr. GitHub displays HTML source instead of running the preview.

## Editing

The linked `[name]` and `[url]`, then the `[text]` title or contact status, are the first editable fields in each snippet. Time, GIF URLs and the `pk-copy` writing follow. Decorative markup and the stylesheet link are at the bottom. Posting HTML and CSS contain no comments, hidden tips, editing notes or instruction blocks.

The preview displays **Dexter & Happy** on threads and buds and **Happy** as the sample contact. Copying keeps `[name]`, `[url]` and `[text]` until you change the corresponding fields. **Copy code** and **Download .txt** use your current edits. Each design keeps its edits while the preview remains open; **Reset design** restores its defaults.

Use ordinary `<p>` paragraphs for writing. Comms use one plain `<p>` per message and accept successive opening `<p>` tags without closing tags. `data-flow="received"`, `"sent"` and `"alternate"` select message direction without repeated message classes. Device hardware is decorative.

The preview editor converts `[b]`, `[i]` and `[u]` into HTML formatting. When editing a raw `[dohtml]` snippet directly, use `<b>`, `<i>` and `<u>`; `<strong>` and `<em>` also work. Bold and underline follow member colours **1 → 2 → 3**; italics reverse them **3 → 2 → 1**. Underline keeps a visible rule. Text accents blend member colours with the neutral text colour for readability.

Buds start with 36 words and suit replies of 100 words or fewer. The preview includes a word counter. Longer writing expands the template instead of being clipped.

## GIFs and themes

The collection has five image-free defaults, seven single-GIF defaults and three paired-GIF defaults. Both supplied Tumblr `.gifv` addresses are retained exactly. Add, remove, replace or crop GIFs in the editor. In raw snippets, remove unwanted `<img>` elements or the complete `pk-media` element. Media-free grid arrangements remove the unused image rows and columns. GIFs use `object-fit:cover`; `object-position` controls the crop.

The Harvest Press applies a monochrome treatment to its first portrait. Other portraits retain their original colour. All decorative artwork is CSS; no icon libraries, downloaded fonts, scripts or generated-image assets are required in forum posts.

Templates inherit the forum's `--mgrgb1`, `--mgrgb2` and `--mgrgb3` RGB triplets. The preview's three palette controls affect the preview only. Posting snippets do not override the member group.

Blue Hour's `html[color-mode="light"]` and `html[color-mode="dark"]` set the neutral surfaces. Explicit forum mode takes precedence over the system preference fallback. CSS is scoped to `.bh-pumpkin` and uses modern grid, `:has()`, `color-mix()` and container queries.

## Source and validation

`designs.json` and `pumpkin-model.js` supply the fifteen snippets and editor defaults. Run `node pumpkin/build.cjs` from the repository root to rebuild the posting files and standalone preview. The stylesheet link is pinned to the immutable commit recorded in `stylesheet-revision.txt`.

HTML/CSS parsing and editor integration checks passed for all fifteen designs. Browser access to the local preview was blocked, so visual rendering and a live JCink post have not been verified. [Validation details](VALIDATION.md).
