## Posting and compatibility

Each masterpost displays its designs above complete copyable code. The examples retain sample writing; code boxes use concise writing markers. Both sets retain Chen & Song, editable GIFs, inherited member colours and forum light/dark support.

Original snippets, editor addresses and hosted stylesheet URLs remain available. The older editor is still at `oats/oats-collection-preview.html`; the newer editor is at `oats/millhouse/oats-collection-preview.html`. Each download contains only its own generation’s posting files, styling and forum posts.

## Rebuilding

Rebuild the older editor with `node oats/build.cjs` or the newer editor with `node oats/millhouse/build.cjs`. Then run `python tools/build_forum_posts.py` and `python tools/build_oats_repositories.py`. Follow the repository defaults to refresh the other split collection packages after a forum rebuild.
