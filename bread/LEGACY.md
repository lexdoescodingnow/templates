# Bread · Legacy

Jinseok & Lucas’s 27 earlier Bread designs, kept separately from the newer 15-design Second Rise collection.

[Download the legacy repository package](bread-legacy-repository.zip) · [Current Second Rise collection](README.md)

| Type | Designs |
| --- | --- |
| Threads | Hearthbound, Levain Letters, Pain de Papier, Sunday Crust, The Proofing Room, Standard, Single Gif, Rounded, Scroll, Split |
| Comms | Batch Chat, Butterwire, Sent, Received, Crumbline, Daily Knead, Toast Talk |
| Buds | Standard, Portrait, Duo, Minimal, Strip, Crustlet, Petit Pain, Pocket Roll, Rye Note, Sesame Kiss |

The package contains individual posting snippets and their supporting stylesheets. Its forum masterpost shows each design above its copyable code; the browser preview includes Copy buttons. Examples retain sample writing while the posting code uses concise writing markers. Hosted stylesheet links are preserved, so existing posts keep working.

The [original named collection guide](bread-original-collection.md) and [original editor](bread-collection-preview.html) remain available.
