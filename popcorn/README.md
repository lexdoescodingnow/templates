# Popcorn · Save me a seat

Fifteen JCink templates for Caleb and Peter. Marquees, striped concession cartons, popped kernels, projection frames and theatre pleats give this collection its own cinema-inspired identity. Member colours drive the headers, borders, image frames, device cases and emphasis; writing stays on neutral surfaces.

[Open the preview/editor file](popcorn-collection-preview.html)

Open a named `.txt` file below, select GitHub’s **Copy raw file**, and paste the entire `[dohtml]` block into your post. Every snippet includes its hosted stylesheet. To use the preview/editor, download the HTML file and open it in your browser; GitHub shows HTML as source.

## Editing and copying

The first editable fields are `[url]`, `[name]` and `[text]`: the linked destination, displayed name, and title or contact status. GIF URLs, comms time, and the writing follow. All editable HTML appears before the decorative element and stylesheet link. There are no comments, hidden tips, instructions or editing notes inside the posting snippets or template CSS.

Replace the lorem ipsum inside `pcn-copy` with your writing. Use ordinary `<p>` paragraphs. Each comms paragraph becomes one message, including when you use successive opening `<p>` tags without closing them. `data-flow="received"`, `"sent"` or `"mixed"` controls message alignment. The device details are decorative.

Inside `[dohtml]`, use `<b>`, `<i>` and `<u>`; `<strong>` and `<em>` also work. Bold and underline have the forward member gradient, 1 → 2 → 3. Italics reverse it, 3 → 2 → 1. The preview/editor also accepts `[b]`, `[i]` and `[u]` and converts them to HTML in the copied code. Literal BBCode inside a raw `[dohtml]` block depends on the forum’s parser, so the ready-to-post snippets use HTML.

Buds are miniature threads for replies around 100 words or fewer. The sample replies contain 36 words. All writing areas grow with their content; no fixed-height scrolling text boxes or hard word limits are imposed.

## GIFs

Both supplied Tumblr placeholder URLs are used exactly as supplied. Both returned HTTP 200 and animated GIF data: 400 × 300 pixels / 70 frames, and 400 × 281 pixels / 53 frames. Five designs begin image-free, six use one GIF and four use two. These are starting layouts, not image-count restrictions.

Use **Add GIF**, **Remove**, the image URL fields and crop-position fields in the editor. In raw snippets, edit or remove `<img>` elements in `pcn-media`. An empty or absent media container disappears, and layouts with image columns give that space back to the text. To add a GIF to an image-free snippet, insert `<div class="pcn-media"><img src="YOUR_GIF_URL" alt="Character GIF" style="object-position:50% 35%"></div>` before `pcn-copy`. Extra images wrap within their assigned media region.

## Preview/editor

The standalone HTML contains the collection styles, all fifteen designs and the editor. The GIFs are its only external visual assets. Preview placeholders show Caleb & Peter and sample titles; exported defaults retain `[name]`, `[url]` and `[text]`.

Choose a design from the list or use **View all 15**. Edit the names, title/status, linked URL, time, message direction, writing, GIF URLs and crop positions. Each design retains its edits while the page remains open. **Copy JCink code** copies the full posting block; if clipboard access is unavailable, the code opens and selects itself for manual copying. **Download .txt** saves the current edited snippet.

Light, dark and system modes, member-palette presets, three colour controls and a narrow-width selector affect the preview only. Exported posts inherit the forum’s member colours and mode. The editor accepts paragraphs, line breaks, emphasis and links; edit the raw snippet for additional HTML your forum allows.

## Forum integration

[popcorn-picturehouse-v1.css](popcorn-picturehouse-v1.css) contains the complete shared styling. Posting links are pinned to the GitHub revision recorded in [stylesheet-revision.txt](stylesheet-revision.txt). Each snippet loads this CSS through its included stylesheet link. Forum posts contain no scripts, and no separate HTML injector is required.

The collection inherits Blue Hour’s RGB triples, `--mgrgb1`, `--mgrgb2` and `--mgrgb3`. If secondary group colours are missing, they fall back to the primary group colour. The sample palette is used only when the member variables are absent. Emphasis colours mix toward the current neutral text colour for readability.

Explicit `html[color-mode="light"]` and `html[color-mode="dark"]` override the system-preference fallback. All collection rules use the `bh-popcorn` and `pcn-` namespaces. The styling uses modern CSS including `:has()`, `color-mix()`, masks and container units. Fonts are local Arial, Georgia and Courier New with fallbacks. The decorative shapes are newly drawn CSS and embedded SVG; no decorative assets were taken from earlier flavour sets. The editor keeps the established collection workflow.

## Build and verification

Run `node popcorn/build.cjs` from the repository root to regenerate all fifteen snippets and the standalone preview. The catalogue is in `designs.json`; `popcorn-model.js` defines the editable markup and sample writing.

Run `NODE_PATH=/path/to/dependencies/node_modules node popcorn/validate.cjs` with `jsdom` and `css-tree` installed to check snippet structure, CSS syntax and editor behaviour. See [VALIDATION.md](VALIDATION.md) for the completed checks and visual-preview limitation.
