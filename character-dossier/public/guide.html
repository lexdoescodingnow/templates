A shared editor, your own drafts.

Lex and Sara can use the same editor link. Each browser keeps its own saved drafts; changes do not appear in the other person’s copy automatically.

Choose, edit and post

  1. Choose any of the 181 characters, or create a new one.
  2. Edit the named fields. Header photos set the colours automatically. Connections, songs and story entries have their own add buttons.
  3. Choose Copy forum post, then paste it into the character’s Blue Hour development post. Later edits need to be copied to the forum again.

Pass changes to one another

  1. Open Save & share. Choose Save this character for one profile, or Save whole library for everything.
  2. Send that downloaded backup file to the other person. Its contents do not need to be opened or edited.
  3. They open the editor, choose Import a backup, and select the file. Import asks before replacing matching character drafts; other characters stay unchanged.

Save a backup of your own edits before importing someone else’s version. Exchange a single-character backup when only that character needs updating.

Moving from a downloaded copy

Open the downloaded editor where your existing drafts are saved. Choose Save & share → Save whole library. Then open this online editor and choose Import a backup. Your downloaded copy stays unchanged.

What gets saved

Browser saving works in this browser on this website. A different browser or device has its own drafts; moving between a downloaded copy and this website also needs a backup. Download backups regularly, especially before moving devices or clearing browser data.

The online editor does not require a GitHub account. Its save buttons do not publish to GitHub or edit forum posts. Photos, music and maps need an internet connection.

Story dates and supplied details

The timeline uses an in-world date when you provide one, otherwise the topic start date. Known topics fill their dates automatically. New topics can fill their date when the post is viewed or previewed on Blue Hour.

Updated supplied details preserve your edits. If a source update conflicts with your draft, choose Review source updates and select only the changes you want.
