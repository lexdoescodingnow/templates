## Posting

Open any named `.txt` file in GitHub, choose **Raw**, then copy the entire `[dohtml]` block into your post. Each snippet includes the hosted stylesheet link at the bottom; all 15 designs share `toffee-collection-v1.css`.

Edit `[url]`, `[name]` and `[text]` first, then the GIF URLs and the reply paragraphs immediately below. Either portrait can be removed. `object-position` controls cropping. Comms timestamps and receipts are also editable. The phone composer is decorative.

The preview/editor opens locally after downloading. Switch between Threads, Comms and Buds, select any of the five names, edit fields, change GIF crops, and use **Copy JCink code** or **Download .txt**. Each design keeps its edits while you switch. The full gallery below includes every original design and its posting code even when scripts are disabled.

Use native `<b>`, `<i>` and `<u>` inside `[dohtml]`. The editor accepts `[b]`, `[i]` and `[u]` and converts them into the native HTML tags. Bold/underline follow group colours 1 → 2 → 3; italics use 3 → 2 → 1. Member palettes are inherited through `--mgrgb1`, `--mgrgb2`, and `--mgrgb3`; editor colour controls affect only the preview.

Comms use one ordinary `<p>` for each message. Fully closed paragraphs and successive opening `<p>` tags both work. Bud samples contain fewer than 100 words; the editor word counter encourages the same limit without cutting off your text.

Explicit Blue Hour `html[color-mode="light"]` and `html[color-mode="dark"]` modes override the operating-system preference. The system preference is used when neither attribute is present.

Google Fonts provide DM Sans, Cormorant Garamond and Allura with local font fallbacks. The small candy and caramel-line drawings are included in the stylesheet and need no image hosting. GIFs use the two supplied Tumblr URLs.
