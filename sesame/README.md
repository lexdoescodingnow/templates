# Sesame · Stella & Valerie

Fifteen coordinated JCink templates: five threads, five phone-style comms and five compact buds. Seed silhouettes, sesame pods, tahini curves and halva folds provide the small flavour details. Member colours carry the headers, frames, borders and emphasis; the reading backgrounds stay neutral.

[Download the preview and editor](https://github.com/lexdoescodingnow/templates/raw/refs/heads/main/sesame/sesame-collection-preview.html)

Open any named `.txt` file below and select **Copy raw file** on GitHub. Paste the complete block into your JCink post. The `[dohtml]` tags and stylesheet link are already included. Download the HTML editor and open it in your browser to view and edit the designs; GitHub’s file viewer displays HTML source.

## Editing

The first editable line contains `[url]` and `[name]`; the next contains `[text]`. Any message time and character images follow, then the lorem ipsum writing. Decoration and the stylesheet link come last. Posting HTML and CSS contain no comments, hidden tips or instructions.

The preview substitutes Stella & Valerie, or Valerie as the single comms contact, for display. The original snippet keeps `[name]`, `[url]` and `[text]` until you replace them. The editor exports your current field values with Copy code or Download .txt. Changes stay with each design while the editor remains open; Reset design restores its defaults.

Use ordinary `<p>` elements for paragraphs and separate message bubbles. Successive opening `<p>` tags work without repeated classes or per-message divs. Comms have received, sent and alternating layouts through `data-flow`. Device controls are decorative. Buds start at 36 words and suit replies of 100 words or fewer; extra writing is not cut off.

The editor accepts `[b]`, `[i]` and `[u]` and converts them to `<b>`, `<i>` and `<u>`. For direct editing of raw `[dohtml]` snippets, use those HTML tags. `<strong>` and `<em>` work too. Bold and underline use member colours 1 → 2 → 3; italics use 3 → 2 → 1. Underlining retains a visible line, and emphasis colours mix toward the neutral text colour for readability.

## Images and member colours

The supplied Tumblr GIF addresses are retained exactly, including `.gifv`. Six designs start without images, six start with one, and three start with two. These are starting layouts, not image limits. Add GIF, Remove and crop controls update the preview and exported code together. Image-free designs can also accept GIFs. In a raw snippet, remove an unwanted `<img>` element; empty image containers collapse and the relevant layout reflows.

The inherited `--mgrgb1`, `--mgrgb2` and `--mgrgb3` comma-separated RGB variables supply the group palette. Place the snippet inside the forum’s member-colour scope. The three preview colour controls affect only the preview, so exported snippets keep inheriting the current member’s colours.

Blue Hour’s `html[color-mode="light"]` and `html[color-mode="dark"]` take precedence over the system preference fallback. The preview provides light/dark selection and Fit, 320 px and 550 px widths. Posting styles are scoped to `.bh-sesame-atelier`. The templates require no JavaScript, external fonts or icon libraries; they use modern CSS including `:has()`, `color-mix()` and container queries.

## Source

`designs.json` and `sesame-model.js` generate the named snippets. Run `node sesame/build.cjs` from the repository root to rebuild them and the standalone editor. The posting stylesheet is pinned to the immutable GitHub commit recorded in `stylesheet-revision.txt`.
