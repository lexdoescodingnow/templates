# Mocha & Latte · The soft blend

Fifteen JCink templates for **Taeyang, Elias and Yujun**: five threads, five electronic comms and five compact buds. Latte-art feathers, flowing milk contours, cocoa crosshatching and three-part portrait compositions form the collection. Member colours carry the headers, frames, borders and emphasis; writing sits on neutral light or dark backgrounds.

[Preview and editor](mocha-latte-collection-preview.html) · [Complete collection](mocha-latte-collection.zip)

Open a named `.txt` below and choose **Copy raw file**. Paste the complete block, including `[dohtml]`, the stylesheet link and `[/dohtml]`, into the forum. The stylesheet loads automatically; no separate script or skin installation is needed where external stylesheets are permitted.

Download the preview HTML and open it in your browser to view, edit and copy all fifteen designs. Its styling and editor are included in the file. GitHub displays HTML as source; the character GIFs load online.

## Editing and formatting

Every posting snippet starts with `[url]`, `[name]` and `[text]`, followed by the time on comms, any GIFs and the writing. All editables precede decorative markup and the stylesheet link. There are no comments, hidden tips or instruction blocks inside the posting snippets or template CSS.

`[name]` can contain one character, a recipient or the shared trio. The preview displays **Taeyang · Elias · Yujun**; copied defaults retain the placeholders. `[text]` is the title on threads/buds and contact status on comms. Replace the lorem ipsum with ordinary HTML paragraphs.

Each plain `<p>` becomes one comms message. Successive opening `<p>` tags work without explicit closing tags. The wrapper's `data-flow` accepts `received`, `sent` or `mixed`. The phone and watch controls are decorative. Bud samples are 36 words and are intended for replies around 100 words or fewer; longer writing remains visible.

The editor converts `[b]`, `[i]` and `[u]` to HTML. When editing raw `[dohtml]` code, use `<b>`, `<i>` and `<u>`; literal BBCode processing inside `[dohtml]` depends on the forum. `<strong>` and `<em>` also work. Bold and underline follow member colours **1 → 2 → 3**; italics reverse them **3 → 2 → 1**. Emphasis colours blend slightly toward the neutral text colour for readability.

## GIFs

All three supplied Tumblr GIF URLs are preserved. Defaults vary between zero, one, two and three images. Use **Add GIF**, **Remove**, the URL fields and crop positions in the editor, or edit the `<img>` tags inside `ml-media` directly. Removing all images collapses the media region and its layout space. Additional images share the available region; these counts are defaults, not limits.

To add images to an image-free snippet, insert the following before `ml-copy`, with as many image elements as needed:

```html
<div class="ml-media">
<img src="[url]" alt="Character GIF" style="object-position:50% 35%">
</div>
```

## Preview and copy

Select a design or **View all 15**. Edit the name, title/status, link, writing, time, message alignment and GIFs. Each design keeps its edits while the page is open. **Copy JCink code** copies the full posting block; **Download .txt** saves the edited snippet. If clipboard access is unavailable, the editor selects the code for manual copying.

Light/dark/system modes, colour presets, three member-colour pickers and width controls affect only the preview. Copied snippets inherit the forum's palette and mode. Save an edited text file to keep changes after closing the preview.

## Forum integration

The shared [mocha-latte-soft-blend-v1.css](mocha-latte-soft-blend-v1.css) is served by jsDelivr at the immutable GitHub revision in [stylesheet-revision.txt](stylesheet-revision.txt). Each snippet includes one stylesheet link after the editable markup.

Inherited RGB triples `--mgrgb1`, `--mgrgb2` and `--mgrgb3` drive the design. Missing secondary colours fall back to an available member colour. The example palette applies only when forum member colours are absent. Explicit `html[color-mode="light"]` or `html[color-mode="dark"]` takes precedence over the system preference.

Template styles are scoped to `.bh-mocha-latte`; inner classes use `ml-`. Modern CSS includes grid, container units, `:has()`, `color-mix()`, text clipping and masks. Fonts use local Baskerville, Palatino, Georgia, Verdana, Arial and Courier fallbacks. Decorative art is CSS and embedded SVG; no external font or icon service is required.

## Maintenance and verification

Run `node mocha-latte/build.cjs` from the repository root to regenerate all posting snippets and the standalone preview. `designs.json` and `mocha-latte-model.js` provide the shared catalogue, defaults and markup used by the editor and exports.

Run `NODE_PATH=/path/to/node_modules node mocha-latte/validate.cjs` with `jsdom` and `css-tree` installed. See [VALIDATION.md](VALIDATION.md) for checks and their limits.
