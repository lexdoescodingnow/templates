12 reply templates: three thread styles, three miniature buds, and a hacked counterpart for each. Change the character name, GIF URL and reply at the top. Names can link to a profile. Buds suit replies of about 100 words or fewer.

Member-group colours are inherited automatically. Use HTML <b>, <i> and <u> inside dohtml; the forum's converted formatting receives the same gradients. Each reply has its own name and avatar, so several characters can post with matching designs.

Short posting code uses the shared hosted stylesheet. Self-contained code includes its CSS and works immediately without hosting. The hacked effects leave the writing still and readable, with reduced-motion support.
