# Leafie Awards

13 templates: three threads, three miniature buds, six hacked counterparts, and Dead Air Descent, the progressive time-jump divider.

[Browse previews and copy short posting codes](https://raw.githack.com/lexdoescodingnow/templates/main/leafie-awards/index.html)

- [All 13 posting snippets](leafie-awards-all-snippets.txt)
- [Forum-ready masterpost](leafie-awards-forum-masterpost.txt)
- [Time-jump divider](leafie-blackout-time-jump.txt)

Use **Copy posting code**. Every snippet contains editable HTML and a single hosted stylesheet link; the CSS stays on GitHub. Paste the entire snippet, including dohtml tags, into the forum. Edit the name, GIF URL and writing at the top. Plain paragraphs separate writing. Buds suit replies around 100 words or fewer.

Member-group colours, forward bold/underline gradients, reversed italic gradients, Blue Hour light/dark modes, mobile layouts and reduced motion are supported. The time-jump divider becomes darker and more fractured down its length.

Rebuild from the repository root: `node leafie-awards/build.cjs`, `node leafie-awards/build-web.cjs`, `node leafie-awards/build-blackout.cjs`, then `node leafie-awards/package.cjs`.
