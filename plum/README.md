# Plum · The Lasting Season

Fifteen JCink templates inspired by the Plum poster: fine flowering branches, satin-like contours, fruit-stone engravings and romantic typography. Member colours shape the headers, frames and emphasis; reading surfaces stay neutral.

[Preview and editor](plum-collection-preview.html) · [Complete collection ZIP](plum-lasting-season.zip)

Download the HTML preview and open it in a browser. It contains all template styling and editor code. GitHub displays HTML as source; the `.txt` files below are ready to copy directly.

## Copy and edit

Open a named `.txt` file and use GitHub's **Copy raw file**. Paste the whole block, including `[dohtml]` and `[/dohtml]`, into your post. Each snippet contains the editable HTML and one hosted stylesheet link. No JavaScript or HTML injector is needed in forum posts.

`[url]`, `[name]` and `[text]` are the first fields. `[url]` is the link destination, `[name]` is the linked name, and `[text]` is the title or comms status. Time, GIFs and the lorem ipsum reply follow, before any decoration and the stylesheet link. Replace the lorem ipsum inside `plm-copy` with your writing. There are no comments, hidden tips, editing notes or separator banners inside the posting snippets or template CSS.

Use ordinary `<p>` paragraphs. In comms, each paragraph becomes a separate message. Successive opening `<p>` tags also work without closing each paragraph manually. Set `data-flow="received"`, `"sent"` or `"mixed"` for message direction; mixed alternates directions. Device keys, status shapes and composer bars are decorative.

Inside `[dohtml]`, use `<b>`, `<i>` and `<u>` for emphasis; `<strong>` and `<em>` are also supported. Bold and underline use member colours 1 → 2 → 3. Italics reverse them to 3 → 2 → 1. The editor converts `[b]`, `[i]` and `[u]` into HTML when copied. Literal BBCode handling inside `[dohtml]` depends on the forum, so the ready-to-use snippets use HTML.

Seven designs start without GIFs, six have one and two have a pair. The supplied Tumblr URLs are retained exactly and both returned animated GIF data. In the editor, use **Add GIF** and **Remove** to adjust any design. When editing code directly, remove an unwanted `<img>` or the entire `plm-media` div. Empty media disappears and portrait columns reflow. Add `<div class="plm-media"><img src="YOUR_GIF_URL" alt="Character GIF"></div>` above `plm-copy` to give an image-free design a GIF. Use `object-position` on each image to adjust its crop. Images never serve as backgrounds behind the reply text.

Buds are designed for replies of 100 words or fewer. Their samples contain 36 words; the editor shows a word count. Longer writing grows naturally rather than being truncated.

## Preview editor

Choose a named design, step between designs, or open **View all 15**. Edit the name, title/status, URL, time, GIFs, crop position and writing. The preview and exported code update together, and each design keeps its own edits while the page remains open. **Download .txt** saves an edited snippet for later.

The preview includes light, dark and system modes; member-colour presets and three custom colour pickers; full, 375 px and 320 px post widths; a full gallery; and a posting-code view. Palette and mode controls affect the preview only. Copied code inherits the forum's member colours and mode. If clipboard access is unavailable, the editor selects the code for manual copying.

The editor accepts paragraphs, line breaks, emphasis, links and blockquotes. Its basic HTML cleanup removes scripts, embedded content and custom attributes from the writing field. For other forum-supported HTML, edit the downloaded snippet directly.

## Forum integration

The shared stylesheet is [plum-lasting-season-v1.css](plum-lasting-season-v1.css). Each posting snippet uses a jsDelivr URL pinned to the revision in [stylesheet-revision.txt](stylesheet-revision.txt). The forum must allow external stylesheets inside `[dohtml]`.

Inherited `--mgrgb1`, `--mgrgb2` and `--mgrgb3` RGB triples drive the full collection. Poster-inspired fallback colours apply only when those variables are absent. Emphasis is deepened in light mode and lightened in dark mode. Blue Hour's explicit `html[color-mode="light"]` and `html[color-mode="dark"]` override the operating-system preference. Styles use the `.plm` wrapper and unique `plm-` design classes.

Cormorant Infant and Manrope are served by Google Fonts under collection-specific CSS font names, with Georgia and Arial fallbacks. The original branch, five-petal blossom and plum-stone vectors are encoded into the stylesheet. No separate decorative image is required. GIFs, web fonts and the forum stylesheet need network access. Layouts use modern CSS including `color-mix()`, `:has()` and container query units.

## Source and verification

Run `node plum/build.cjs` from the repository root to rebuild the stylesheet, design index, fifteen snippets and standalone preview. The model is the single source of template markup, defaults and names. For a stylesheet update, publish the new CSS revision, update `stylesheet-revision.txt`, and rebuild the posting files.

Run `node plum/validate.cjs` with Playwright and Chromium installed. `PLUM_BROWSER` optionally points to a browser executable; `PLUM_ASSET_MAP` optionally points to a local map of downloaded preview fonts and GIFs for repeatable rendering. Validation does not post to the forum.

See [VALIDATION.md](VALIDATION.md) for the completed checks.
